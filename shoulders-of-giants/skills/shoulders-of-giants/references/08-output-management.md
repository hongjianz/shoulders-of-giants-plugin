# 08: 输出管理与持久化

## 输出目录规范

- **默认输出目录**: `outputs/`（相对当前工作目录，显式目录方便查找）
- **备选目录（隐藏存储）**: `.shoulders-of-giants/outputs/`（供跨会话引用，不推荐直接交付）
- **命名格式**: `<YYYY-MM-DD>-<topic-slug>.md`
- **会话管理**: 会话结束时提醒用户保存或清理输出文件
- **跨会话引用**: 输出文件可作为后续分析或 industry-analysis 插件的输入

## 综合报告结构（必选）

综合报告必须包含以下部分：

```
# 标题：调研主题

## 执行摘要
[3-5句话概述：核心发现 + 总体置信度]

## 调研方法
[数据源列表、检索策略、流程概述]

## 核心发现（逐条标注水印）
[按证据等级从高到低排列]

## 对抗验证结果
[置信度调整汇总表]

## 产业影响时间线（可选）
[deep模式强制执行，标准模式可简略]

## 信息缺口声明
[本调研未能覆盖的关键信息]

## 数据源列表
[所有引用源的完整列表，含DOI/URL]
```

详细报告模板见 `06-synthesis-report.md`。

## 文件持久化策略

- 分析完成后，如果用户要求则输出到文件
- 所有输出文件放在 `.shoulders-of-giants/outputs/` 下
- 输出文件命名应保持一致性，便于后续引用

## 跨插件证据传递

当同时安装了 **industry-analysis** 插件时，shoulders-of-giants 生成的证据摘要可作为产业分析输入：

### 证据摘要格式

```
## 证据摘要 → industry-analysis 输入

### 关键发现（带水印）
1. [发现1] 🔒 — 简要描述
2. [发现2] 📄⭐ — 简要描述

### 对抗验证结果
| 原主张 | 调整后置信度 | 反方证据 |
|-------|-------------|---------|

### 信息缺口
- [缺口1]: [说明]

### 推荐分析方向
- [方向1]: [基于证据的建议]
```

### 使用流程

1. shoulders-of-giants 输出证据摘要（可在报告末尾附加）
2. 用户启动 industry-analysis：`/industry-analysis <主题>`
3. 用户将证据摘要中的关键发现作为输入参考
4. industry-analysis 基于证据进行产业解读和情景规划

详见 `10-integration-industry-analysis.md`（完整集成工作流）。
