# 证据水印系统

> 优化项 #4 — 每条发现自动标注验证链，让读者能一目了然地判断可信度

## 水印符号体系

```
符号     含义                    适用场景
────────────────────────────────────────────────────────
🔒       经过交叉验证             同上+对抗验证通过
📄       单一来源                 仅一个数据源
🏢       产业资讯/公司公告         新闻稿、公司官网
🔬       预印本/未出版             bioRxiv、arXiv
⚡       发现矛盾                 不同来源结论冲突
❓       单一声称/未验证           只有一家声称，无独立验证
```

## 水印规则矩阵

```
可用数据源数量:
  1个源     → 📄 (单一来源)
  2+个源     → 检查来源类型
  
交叉验证:
  不同源结论一致     → 升级到 🔒
  不同源结论冲突     → ⚡ 标记为冲突

来源类型加权:
  至少1个同行评议   → 额外标记 ⭐
  仅有预印本       → 🔬 (自动下调一级)
  仅有产业资讯     → 🏢 (需标注来源)

对抗验证结果:
  对抗验证通过     → 🔒 (锁定)
  对抗验证发现矛盾 → ⚡ (争议)
  未做对抗验证     → 保持原始标记
```

## 显示格式

在报告中使用：

```markdown
### [发现标题]  🔒 | ⭐⭐⭐⭐

发现内容......

验证链: PubMed → Consensus → 对抗验证通过
对抗验证: 3角度中3角度通过
```

## 完整分类

```
信源质量等级 (从高到低)
─────────────────────────────────────────
🔒 交叉验证+对抗通过   最高可信
🔒⭐ 交叉验证+含同行评议  高可信
📄⭐ 单一同行评议源     中等可信  
📄  单一非评议源       低可信
🏢  公司/产业资讯      需核实
🔬  预印本            未出版
⚡  争议中            正反证据并存
❓  单一声称          未独立验证

适用场景:
🔒 → 交叉验证+对抗均通过 (最可靠的结论)
🔒⭐ → 多源一致且含论文 (高可信度)
📄⭐ → 单篇论文支持 (有据可查但需注意)
📄 → 单一非学术来源 (谨慎对待)
🏢 → 公司新闻稿/官网 (夸大风险最高)
🔬 → 预印本 (需要追踪后续发表)
⚡ → 结论分歧点 (值得深入)
❓ → 无法独立验证的声称
```
