# 07: 时间序列分析

> v1.0 新增 — 将收集到的发现按时间维度组织，生成时间线因果关联分析。

## 核心理念

时间序列分析不是简单的"按时间排列事件"，而是通过时间维度识别：

1. **发现之间的因果链** — A 发生后才有的 B，还是巧合？
2. **技术成熟度轨迹** — 从基础研究到产品化的演进路径
3. **关键转折点** — 哪些事件改变了行业/技术的发展方向
4. **预测基准** — 基于历史轨迹对未来的合理预期

## 适用条件

时间序列分析适用于以下场景：

```
必须条件：
  收集到的发现中有足够的时序信息（至少跨越12个月）
  包含可排序的里程碑事件（论文发表/融资/产品发布/政策出台）

强烈推荐：
  产业趋势评估 ✓
  技术可行性评估 ✓
  竞争格局分析 ✓

不适用（跳过此阶段）：
  纯概念/理论综述
  无法获取事件日期
  时间跨度不足
```

## 四步分析法

### 第1步：事件提取与排序

从已收集的所有发现中提取可确定时间的事件，按时间线排列：

```
格式:
  YYYY-MM | 事件 | 类型 | 信源 | 影响

示例:
  2022-06 | 某团队发表AI酶设计方法论文 | 技术突破 | 🔒 | 触发领域关注
  2023-01 | 某初创公司成立（基于该方法） | 商业化 | 📄⭐ | 技术从学术走向产业
  2023-09 | 完成A轮融资 | 融资 | 🏢 | 资本确认
  2024-03 | 首个产品原型公开 | 产品 | 📄⭐ | 可行性验证
  ...
```

### 第2步：因果链分析

寻找事件之间的因果关系，区分"强关联"与"弱关联"：

```
因果关系判定规则:
──────────────────────────────────

📌 强因果（确信度高）
  特征:
    - 事件B在事件A之后发生
    - 事件B明确引用A作为必要条件
    - 存在中间桥梁事件连接A→B
  示例: "论文发表" → "基于该论文成立公司" → "获得融资"
  水印: 🔒 可标注

📎 弱因果（推测性）
  特征:
    - 事件B在A之后发生，但无直接引用关系
    - 可能存在共同的外部驱动因素
  示例: "竞品A获得融资" → "竞品B调整策略"
  水印: 📄 需标注"推测性关联"

❌ 伪关联（需排除）
  特征:
    - 时间上先后但逻辑上无关
    - 属于同一时期的不同领域进展
  示例: "AI突破"与"某材料领域进展"同步但无关
  处理: 不要在报告中构建虚假关联
```

### 第3步：关键转折点识别

从时间线中识别出改变发展轨迹的关键节点：

```
转折点判定标准:
  至少满足以下条件之一:
  □ 该事件被后续多个来源引用
  □ 事件发生后领域内出现了明显方向变化
  □ 资本/政策/人才在该事件后显著流入

转折点类型:
  🧪 技术突破 — 验证了之前不可行的路线
  💰 资本注入 — 大额融资或巨头入场
  📋 政策变化 — 监管/标准/资助方向变化
  🏢 关键退出 — 关键玩家的进入或退出
  🔬 实验结果 — 正面或负面的关键数据

每个转折点标注:
  ┌─────────────────────────────────┐
  │ 转折点: [事件名称]              │
  │ 日期: YYYY-MM                   │
  │ 类型: [🧪/💰/📋/🏢/🔬]         │
  │ 证据: [支持该转折判断的发现引用] │
  │ 影响: [对后续发展的具体影响]     │
  └─────────────────────────────────┘
```

### 第4步：阶段性总结与预测基准

基于时间线的阶段性特征，对当前阶段进行定位并给出合理的未来预期范围：

```
时间阶段划分:
─────────────────────────────────────────

阶段1: 基础研究期
  特征: 论文发表、方法学突破、概念验证
  典型跨度: 1-3年
  可预期: 学术热度增长，可能出现衍生团队

阶段2: 转化期
  特征: 初创公司成立、专利申请、种子轮融资
  典型跨度: 1-2年
  可预期: 产品开发启动，大厂开始关注

阶段3: 成长期
  特征: 产品发布、规模化、A/B轮融资
  典型跨度: 2-4年
  可预期: 竞争加剧，可能出现标准化/监管框架

阶段4: 成熟期
  特征: 市场形成、龙头出现、价格竞争
  典型跨度: 持续
  可预期: 并购整合，新进入者壁垒提高

⚠ 当前阶段的定位基于收集到的信息，随新信息更新。
```

## 输出格式

在综合报告中，时间序列分析产出以下三个区块：

### 时间线概览（必选）

```markdown
## 发展时间线

| 时间 | 事件 | 类型 | 可信度 | 因果关联 |
|------|------|------|--------|---------|
| 2022-Q2 | 论文: ... | 🧪技术 | 🔒 | — |
| 2023-Q1 | 成立公司: ... | 🏢产业 | 🔒 | ←论文 |
| 2023-Q3 | A轮融资: ... | 💰资本 | 🏢 | ←成立 |
| 2024-Q2 | 产品原型: ... | 📦产品 | 📄⭐ | ←融资 |
```

### 关键转折点（推荐）

```
### 转折点: AI酶设计方法论文发表（2022）

类型: 🧪 技术突破
证据: 该论文被后续至少5个独立来源引用，催生了至少3家衍生公司
影响: 确立了序列空间跳过的技术路线，使中国团队获得差异化竞争优势
```

### 产业影响时间线（推荐——包含最终报告中的时间线表格）

```markdown
| 时间阶段 | 影响程度 | 可信度 | 说明 |
|---------|---------|--------|------|
| 短期1-2年 | ... | ... | ... |
| 中期2-3年 | ... | ... | ... |
| 长期3-5年 | ... | ... | ... |
```
