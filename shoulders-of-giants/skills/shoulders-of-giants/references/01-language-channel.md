# 语言通道评估模板

> 优化项 #1 — 在检索计划阶段自动评估并加入多语言检索通道

## 评估规则

当问题满足以下条件时，自动触发对应语言通道：

```
中国相关关键词集合:
  - 地域词: "中国" / "China" / "Chinese" / "国内" / "上海" / "北京"
  - 公司名: 天鹜 / 分子之心 / 百奥几何 / 华大 / 迪安
  - 技术名: CPDiffusion / Venus / PLMeAE / MoleculeOS
  - 作者名: 洪亮 / 许锦波 / 张 / 王 / 李 / 刘 (等常见中文学者姓氏)

日本/韩国相关:
  - "日本" / "Japan" / "Japanese" / "東京"
  - "韓国" / "Korea" / "Korean"

欧洲相关(非英语):
  - 非英语国家机构 / EU-funded
```

## 检索计划模板中的语言段

在生成检索计划时，加入以下区块：

```markdown
## 🌐 语言覆盖评估

| 语言 | 需要 | 理由 | 关键词(中文/其他) |
|------|------|------|------------------|
| English | ✅ 主要 | [自动: 默认] | [从主关键词自动翻译] |
| 中文 | [是/否] | [匹配到中国相关信号] | [需人工补充] |
| 其他 | [是/否] | [匹配到对应地域信号] | [需人工补充] |

确认要点:
  □ 中文关键词是否需要修正？
  □ 是否遗漏了地区性的学术数据库？
```

## 使用时机

在「检索计划生成 → 用户确认」之间插入语言评估步骤。

## 本次案例的复盘

本调研的初始检索计划 **未包含中文通道**，导致天鹜科技、分子之心、CPDiffusion
等关键的中国团队/技术在第一轮收集中完全未被发现。这是最需要吸取的教训之一。
