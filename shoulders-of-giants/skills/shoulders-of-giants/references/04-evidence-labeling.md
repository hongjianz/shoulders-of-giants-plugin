# 04: 证据分层与水印标注

## 证据水印系统

### 符号体系

```
符号  含义                    适用场景
─────────────────────────────────────────
🔒   交叉验证+对抗通过         同一发现被多个独立源证实
📄⭐ 单篇同行评议              有DOI可追溯的论文
📄   单一非评议源              单一来源且非学术
🏢   产业资讯/公司公告         新闻稿、官网、融资公告
🔬   预印本                   bioRxiv、arXiv未出版
⚡   发现矛盾                  不同来源结论冲突
❓   单一声称/未独立验证        仅一家之言
```

### 分配规则

```
可用数据源数量:
  1个源     → 📄 (单一来源)
  2+个源一致 → 检查来源类型

来源类型:
  至少1个同行评议 → 额外标注 ⭐
  仅有预印本     → 🔬 (自动下调一级)
  仅有产业资讯   → 🏢

对抗验证结果:
  3角度通过     → 🔒 (锁定)
  发现矛盾      → ⚡ (争议)
  未做对抗验证  → 保持原始标记
```

### 水印规则矩阵

更详细的组合逻辑：

```
可用数据源数量:
  1个源     → 📄 (单一来源)
  2+个源     → 检查来源类型
  
交叉验证:
  不同源结论一致     → 升级到 🔒
  不同源结论冲突     → ⚡ 标记为冲突

来源类型加权:
  至少1个同行评议   → 额外标记 ⭐
  仅有预印本       → 🔬 (自动下调一级)
  仅有产业资讯     → 🏢 (需标注来源)

对抗验证结果:
  对抗验证通过     → 🔒 (锁定)
  对抗验证发现矛盾 → ⚡ (争议)
  未做对抗验证     → 保持原始标记
```

### 完整分类 (按可信度从高到低)

```
信源质量等级 (从高到低)
─────────────────────────────────────────
🔒 交叉验证+对抗通过   最高可信
🔒⭐ 交叉验证+含同行评议  高可信
📄⭐ 单一同行评议源     中等可信  
📄  单一非评议源       低可信
🏢  公司/产业资讯      需核实
🔬  预印本            未出版
⚡  争议中            正反证据并存
❓  单一声称          未独立验证

适用场景:
🔒 → 交叉验证+对抗均通过 (最可靠的结论)
🔒⭐ → 多源一致且含论文 (高可信度)
📄⭐ → 单篇论文支持 (有据可查但需注意)
📄 → 单一非学术来源 (谨慎对待)
🏢 → 公司新闻稿/官网 (夸大风险最高)
🔬 → 预印本 (需要追踪后续发表)
⚡ → 结论分歧点 (值得深入)
❓ → 无法独立验证的声称
```

### 展示格式

在报告中每条发现使用：

```markdown
### [发现标题]  🔒 | ⭐⭐⭐⭐

核心发现内容......

验证链: PubMed → Consensus → 对抗验证通过
对抗验证: 3角度中3角度通过
来源: [DOI链接/URL]
```

## 证据分层标准

```
等级        定义                    示例
────────────────────────────────────────────
Level 1   系统综述/荟萃分析          Cochrane Review
Level 2   RCT / 大规模队列研究       Nature Comms RCT
Level 3   基础研究/方法学论文         Cell Discovery方法
Level 4   综述/观点文章             Trends in Analytical Chemistry
Level 5   预印本                   最新未出版研究
Level 6   产业资讯/公司公告         融资新闻、产品发布
```

## 水印组合语法 (v1.0)

### 基本原则
每条发现最多标注 **2 个符号**:
- 第1位: 可信度基础符号 (🔒 / 📄 / 🏢 / 🔬 / ⚡ / ❓) — *必选*
- 第2位: 质量修饰符 (⭐ / 无) — *可选, 仅当有同行评议时*

### 合法组合表

| 组合 | 含义 | 生成条件 |
|------|------|---------|
| 🔒 | 交叉验证通过, 无同行评议 | 2+数据源一致, 均为非评议源 |
| 🔒⭐ | 交叉验证通过, 含同行评议 | 2+数据源一致, 至少1个同行评议 |
| 📄 | 单一非评议源 | 1个数据源, 非学术 |
| 📄⭐ | 单篇同行评议 | 1个数据源, 有DOI论文 |
| 🏢 | 产业资讯 | 公司新闻稿/官网/融资公告 |
| 🔬 | 预印本 | bioRxiv/arXiv, 未出版 |
| ⚡ | 争议/矛盾 | 不同来源结论冲突 |
| ❓ | 单一声称 | 无法独立验证 |

### 禁止的组合 (LLM 不可自行创造)

以下组合在测试运行中出现过但未定义, **现明确禁止**:
- ❌ **🔒⭐⭐** — 三重符号, 无效
- ❌ **🔒🏢** — 可信度符号冲突, 交叉验证 ≠ 产业资讯
- ❌ **❓🏢** — 单一声称 ≠ 产业资讯, 选择其一
- ❌ **📄⭐⭐** — 无"双星"概念, ⭐最多1个
- ❌ **任何3符号及以上组合** — 最多2个符号

### 例外处理
- 若某条发现同时满足 🔒 和 🏢 的条件: 取 🔒 (更高可信度)
- 若某条发现同时满足 🔒 和 🔬 的条件: 取 🔒 (交叉验证优先)
- 若某条发现既无交叉验证又无单一来源: 取 ❓

```markdown
─────────────────|────────|───────────|─────

```
