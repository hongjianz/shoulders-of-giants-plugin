# 04: 证据分层与水印标注

## 证据水印系统

### 符号体系

```
符号  含义                    适用场景
─────────────────────────────────────────
🔒   交叉验证+对抗通过         同一发现被多个独立源证实
📄⭐ 单篇同行评议              有DOI可追溯的论文
📄   单一非评议源              单一来源且非学术
🏢   产业资讯/公司公告         新闻稿、官网、融资公告
🔬   预印本                   bioRxiv、arXiv未出版
⚡   发现矛盾                  不同来源结论冲突
❓   单一声称/未独立验证        仅一家之言
```

### 分配规则

```
可用数据源数量:
  1个源     → 📄 (单一来源)
  2+个源一致 → 升级到 🔒

来源类型:
  至少1个同行评议 → 额外标注 ⭐
  仅有预印本     → 🔬 (自动下调一级)
  仅有产业资讯   → 🏢

对抗验证结果:
  3角度通过     → 🔒 (锁定)
  发现矛盾      → ⚡ (争议)
  未做对抗验证  → 保持原始标记
```

### 展示格式

在报告中每条发现使用：

```markdown
### [发现标题]  🔒 | ⭐⭐⭐⭐

核心发现内容......

验证链: PubMed → Consensus → 对抗验证通过
来源: [DOI链接/URL]
```

## 证据分层标准

```
等级        定义                    示例
────────────────────────────────────────────
Level 1   系统综述/荟萃分析          Cochrane Review
Level 2   RCT / 大规模队列研究       Nature Comms RCT
Level 3   基础研究/方法学论文         Cell Discovery方法
Level 4   综述/观点文章             Trends in Analytical Chemistry
Level 5   预印本                   最新未出版研究
Level 6   产业资讯/公司公告         融资新闻、产品发布
```

## 交叉验证矩阵

```markdown
数据源1 \ 数据源2 | PubMed | Consensus | Web
─────────────────|────────|───────────|─────
PubMed           |   —    |  🔒高可信 |  🔒高可信
Consensus        |  🔒    |   —       |  🟡中可信
Web              |  🔒    |  🟡       |  📄低可信
```
