## 核心发现（逐条标注）

## 水印在报告中的使用

```
🔒 交叉验证+对抗通过      最可靠的结论
📄⭐ 单篇同行评议         有据可查
🏢 产业资讯              需要关注更新
🔬 预印本                需要追踪发表状态
⚡ 争议中                正反证据并存
❓ 单一声称              待独立验证
```

## 对抗验证结果的整合

对抗验证的发现**必须**被整合到最终结论中，规则如下：

| 对抗结果 | 报告处理 |
|---------|---------|
| 全部✅（找到强反证） | 下调结论置信度，在报告中详细说明反方证据 |
| 部分✅ | 下调相关子主张的置信度，保留主结论但加注 |
| 全部⚪ | 报告标注"对抗验证未发现明显反证" |
| 部分❌ | 在信息缺口声明中记录 |

## 交互模板

```markdown
## 阶段6: 综合报告

调研已完成，核心发现如下：
  [列出3-5条核心发现及水印]

对抗验证的置信度调整：
  [列出调整]

是否现在输出完整报告？也可以选择对某个发现再做补充调研。
```
